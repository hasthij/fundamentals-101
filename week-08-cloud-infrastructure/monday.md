Describe cloud concepts 

&#x20;Cloud computing: shared responsibility, public/private/hybrid models, consumption-based pricing

&#x20;Benefits: high availability, scalability, reliability, predictability, security, governance, manageability

&#x20;Service types: IaaS, PaaS, SaaS, with serverless



Describe Azure architecture and services 

&#x20;Core architecture: regions, region pairs, availability zones, datacenters

&#x20;Resource hierarchy: resources, resource groups, subscriptions, management groups

&#x20;Compute: virtual machines, scale sets, availability sets, containers, App Service, Azure Functions, Virtual Desktop

&#x20;Networking: virtual networks, VPN Gateway, ExpressRoute, DNS, public/private endpoints

&#x20;Storage: storage accounts, redundancy options, access tiers, Blob/Files/Queue/Table, migration tools (AzCopy, Storage Explorer, Azure File Sync, Azure Migrate, Data Box)

&#x20;Identity, access, security: Microsoft Entra ID, Entra Domain Services, authentication (SSO, MFA, passwordless), Conditional Access, Azure RBAC, Zero Trust, defence in depth, Microsoft Defender for Cloud



Describe Azure management and governance 

&#x20;Cost management: factors affecting cost, pricing calculator, TCO calculator, Cost Management tool, tags

&#x20;Governance and compliance: Microsoft Purview, Azure Policy, resource locks, Service Trust Portal

&#x20;Managing and deploying resources: Azure portal, Cloud Shell, CLI, PowerShell, Azure Arc, Infrastructure as Code, ARM templates

&#x20;Monitoring: Azure Advisor, Service Health, Azure Monitor, Log Analytics, Application Insights
